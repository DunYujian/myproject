# 博客音乐

将 MP3 文件放在本目录，提交并推送到 `DunYujian/myproject` 的 `main` 分支。
播放器展开时会读取本仓库的文件列表，自动识别 `.mp3` 和 `.MP3`，显示文件名（不含扩展名）。
不需要 GitHub Token；播放器默认不自动播放，访客点击后才开始播放。

建议使用易读的文件名，如 `歌曲名 - 歌手.mp3`。只上传你有权公开分享的音频。

## 本地歌单

`playlist.json` 是备用歌单，在 GitHub API 无法访问或达到访问限额时使用。
添加、删除或重命名音乐后，在仓库根目录运行：

```powershell
python scripts/update_music.py
```

将更新后的 `playlist.json` 和音乐一并提交。本地预览也使用该歌单。
播放器提供选曲、播放/暂停、进度、音量和上一首/下一首；切换页面会停止当前播放。
当前没有附带示例音乐，空歌单会显示“暂时没有可播放的音乐”。
