# 博客音乐

将 MP3 文件放在本目录，提交并推送到 `DunYujian/myproject` 的 `main` 分支。
播放器展开时会读取本仓库的文件列表，自动识别 `.mp3` 和 `.MP3`，显示文件名（不含扩展名）。
不需要 GitHub Token；播放器默认不自动播放，访客点击后才开始播放。

建议使用易读的文件名，如 `歌手 - 歌曲名.mp3`；播放器会将第一段识别为歌手。也可在歌单中分别指定 `title` 和 `artist`。只上传你有权公开分享的音频。

## 本地歌单

`playlist.json` 是优先使用的本地歌单，GitHub API 会在后台检查新增歌曲，不阻塞已有歌单。
添加、删除或重命名音乐后，在仓库根目录运行：

```powershell
python scripts/update_music.py
```

将更新后的 `playlist.json` 和音乐一并提交。本地预览也使用该歌单。
播放器提供选曲、播放/暂停、拖动进度、音量/静音、上一首/下一首与三种循环模式。
歌曲、进度、音量和模式保存在本机；切换页面会停止播放，再次点击播放后恢复进度。
音频只在访客点击后加载。空歌单或网络错误提供重新加载按钮，不自动跳过失败的歌曲。
