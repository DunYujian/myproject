# 网站资源

[返回仓库首页](../README.md)

| 位置 | 用途 |
| --- | --- |
| `avatar.svg` | 网站头像 |
| `favicon.svg` | 浏览器站点图标 |
| `css/` | 公共主题、侧栏、播放器、评论和动效样式 |
| `js/` | 公共交互、组件、日历、播放器和站内导航 |
| [fonts/](fonts/README.md) | 字体文件、授权与替换说明 |
| `images/<文章名>/` | 按文章归档的图片 |
| `downloads/<专题名>/` | 教程数据、配置示例、预览与 ZIP 附件 |

## 放置规则

- 新文章配图使用自己的子目录，避免不同文章的 `image-01.png` 互相覆盖。
- 音乐放在根目录的 `music/`，各游戏自己的素材与代码放在 `games/<游戏名>/`。
- 字体授权文件与字体一起保留。
- 修改资源位置后同步更新 HTML、CSS 或脚本中的引用。现有图片和教程附件保留原网址。

Origin 教程的附件位于 `downloads/codex-origin/`，其生成方式见 [脚本说明](../scripts/README.md)。
