# 字体搭配

- 博客名、导航和栏目标题：优先匹配访客设备上的瘦金体（方正瘦金书简体 / 汉仪瘦金书 / 华康瘦金体）；未安装时使用随站点托管的 **站酷小薇体**。
- 首页寄语与小装饰：**志莽行书**。
- 文章标题、正文与代码：继续使用原来的系统衬线字体和等宽字体，不套用艺术字体。

没有将商业瘦金字体文件放入仓库。站酷小薇体和志莽行书不等同于瘦金体。
后续如提供允许网页嵌入的瘦金体文件，可在 `reading.css` 的 `Zaiye Shoujin` 字体声明中接入。

## 来源和许可

字体来自 Google Fonts 官方仓库，原始 TTF 转换为 WOFF2 以减少网页下载量，保留原始字形及版权信息。

- [ZCOOL XiaoWei](https://github.com/google/fonts/tree/main/ofl/zcoolxiaowei)：`ZCOOLXiaoWei-OFL.txt`
- [Zhi Mang Xing](https://github.com/google/fonts/tree/main/ofl/zhimangxing)：`ZhiMangXing-OFL.txt`

两款字体均按 SIL Open Font License 1.1 分发，许可证全文随字体保留。
